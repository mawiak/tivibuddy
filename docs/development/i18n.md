# Translations

TiviBuddy uses Flutter's built-in localization tooling with ARB files.

- Source files: `app/lib/l10n/app_<locale>.arb`
- Template (all keys must exist here first): `app_en.arb`
- Maintained by the project: English (`en`) and German (`de`)

The Dart classes (`app_localizations*.dart`) are generated on every `flutter run`, `flutter
build` or `flutter gen-l10n` and are not committed.

## Adding a string

1. Add the key to `app_en.arb`.
2. Add the translation to `app_de.arb` (and every other existing locale).
3. Use it in widgets through `AppLocalizations.of(context).<key>`.

Never hard-code user-facing text in widgets.

## Adding a language

1. Copy `app_en.arb` to `app_<locale>.arb` (for example `app_fr.arb`).
2. Set `"@@locale"` to the new locale and translate all values.
3. Run `flutter gen-l10n`. The new locale is picked up automatically through
   `AppLocalizations.supportedLocales`.
